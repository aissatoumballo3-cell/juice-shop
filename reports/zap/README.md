Rapports DAST / OWASP ZAP

Ce dossier contient les rapports issus de l'analyse dynamique de sécurité de l'application.

L'analyse DAST permet de tester l'application en fonctionnement afin d'identifier des vulnérabilités exploitables au niveau de l'application web.

Les analyses seront réalisées avec OWASP ZAP sur l'application OWASP Juice Shop.

Les rapports générés seront conservés dans ce répertoire.
