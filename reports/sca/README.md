Rapports SCA

Ce dossier contient les rapports d'analyse des dépendances du projet.

L'analyse SCA permet d'identifier les dépendances vulnérables ou obsolètes utilisées par l'application.

Dans ce projet, l'analyse est réalisée avec OWASP Dependency-Check et intégrée au pipeline Jenkins.

Les rapports générés seront conservés dans ce répertoire.
